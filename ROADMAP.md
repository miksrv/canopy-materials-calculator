# ROADMAP — Калькулятор кровли и заборов (виджет)

> Проект: встраиваемый React/TypeScript виджет для расчёта материалов кровли и заборов.  
> Хостинг: статика (без Node.js). Интеграция в CMS (MODx и др.) через `<script>` + `<div id="roof-calc"/>`.  
> Ориентир UI: [metallprofil.ru/calculators/roof](https://orenburg.metallprofil.ru/shop/pokupatelyam/calculators/roof/).

## Формулы расчёта (из calc.xlsx)

### Кровля

#### Односкатная
```
N = ceil(L / X1)          // количество листов
S = X * a * N             // площадь к оплате (м²)
```
- `L` — ширина ската (м)
- `a` — длина листа со свесом (м)

#### Двускатная
```
N = ceil(L / X1)
S = (X * a * N) + (X * b * N)
```
- `a`, `b` — длины листов левого и правого ската со свесом

#### Мансардная
```
N = ceil(L / X1)
S = (X * a * N) + (X * b * N) + (X * c * N) + (X * d * N)
```
- `a`, `b`, `c`, `d` — длины 4 листов (2 верхних + 2 нижних ската) со свесом

#### Вальмовая
```
S = (2*(M*a2/2) + ((K+L)/2)*a * 2) * 1.15    // +15% на нахлёсты
Конёк = K + 4 * sqrt(a2² + (M/2)²)            // п.м.
Фронтонные планки = (a + b + c + d) * 2        // п.м.
```
- `M` — ширина дома (м)
- `K` — длина конька (м)
- `L` — длина дома (м)
- `a` — длина ската длинной стороны (м)
- `a2` — длина ската короткой (торцевой) стороны (м)

#### Шатровая
```
S = (2*(a2*M/2) + 2*(a*L/2)) * 1.15
Конёк = sqrt(a2² + (M/2)²) * 4                // п.м.
```

### Заборы

#### Из профлиста
```
N = ceil(P / X1)          // количество листов
S = X * h * N             // площадь к оплате
F = (P/a + 1) * (h + 0.5) // метраж столбов
K = N * 10                // количество саморезов
M = 2 * P                 // метраж прожилин
```
- `P` — периметр/длина забора (м)
- `h` — высота забора (м)
- `a` — расстояние между столбами (м)

#### Из штакетника
```
N = floor(P / (X + X1))   // количество штакетин
Стоимость = N * h * S
K = N * 4                 // саморезы
```
- `X` — ширина штакетника (мм)
- `X1` — просвет между штакетниками (мм)
- `S` — стоимость метра погонного (руб.)

#### Жалюзи
```
N_ламели = floor(Kh * 13)       // ламелей в секции
Итого п.м. = K * N_ламели * L
Боковые планки = Kh * K * 2    // м.п.
Верхние планки = L * K          // п.м.
```
- `K` — количество секций
- `Kh` — высота секции (м)
- `L` — ширина секции (м)

## Технический стек

| Слой | Технология | Обоснование |
|---|---|---|
| Фреймворк | React 18 + TypeScript 5 | Требование заказчика |
| Сборка | Vite + `lib` mode | Генерирует один `widget.js` без Node |
| Стили | CSS Modules + CSS Variables | Изоляция стилей для виджета |
| Диаграммы | SVG (inline, React) | Нет зависимостей, интерактивность |
| Данные | JSON-файлы (статика) | Хостинг без бэкенда |
| Расчёты | Pure functions (TS) | Тестируемость, клиентская сторона |
| Состояние | React Context + useReducer | Достаточно для виджета |
| Тесты | Vitest | Встроен в Vite |

## Архитектура виджета

```
widget/
├── index.tsx              # точка входа, монтирует <App/> в #roof-calc
├── App.tsx                # корневой компонент, роутинг между Кровля/Забор
│
├── data/                  # JSON с данными (загружаются без сервера)
│   ├── materials.json     # профлист, металлочерепица — X, X1, цвета, цены
│   ├── roof-types.json    # описание типов кровли
│   └── fence-types.json   # описание типов заборов
│
├── engine/                # чистые функции расчёта (без React)
│   ├── roof.ts            # расчёты для 5 типов кровли
│   ├── fence.ts           # расчёты для 3 типов забора
│   └── types.ts           # TypeScript интерфейсы входных/выходных данных
│
├── components/
│   ├── ui/                # атомарные компоненты
│   │   ├── NumberInput/
│   │   ├── RadioCard/     # выбор типа крыши/забора с картинкой
│   │   ├── SelectTabs/    # Кровля / Заборы
│   │   └── ResultTable/
│   │
│   ├── diagrams/          # SVG-схемы с подписями параметров
│   │   ├── RoofSingleSlope.svg.tsx
│   │   ├── RoofDoubleSlope.svg.tsx
│   │   ├── RoofMansard.svg.tsx
│   │   ├── RoofHip.svg.tsx      # Вальмовая
│   │   ├── RoofPyramid.svg.tsx  # Шатровая
│   │   └── FenceDiagram.svg.tsx
│   │
│   ├── RoofCalculator/    # форма + результат для кровли
│   └── FenceCalculator/   # форма + результат для заборов
│
└── styles/
    ├── global.css          # CSS Variables, типографика
    └── widget.css          # сброс стилей для изоляции в CMS
```

## Открытые вопросы к заказчику

1. **Материалы**: помимо профлиста, нужна ли металлочерепица (Каскад, Монтерей)? Если да — нужны их X и X1.
2. **Цены**: отображать стоимость материалов или только количество? Если да — откуда брать цены (hardcode в JSON / API)?
3. **Мансардная**: формула в xlsx неполная. Уточнить: это 4 листа (2 пары скатов) или другая конфигурация?
4. **Цветовая схема**: какие цвета бренда использовать? RAL-палитра нужна?
5. **Конёк и доборные элементы**: нужно считать только листы, или и доборные элементы (конёк, ветровая планка и т.д.)?
6. **Фасад +15%**: в xlsx есть строка "площадь фасада +15%" — это фасадные панели? Это отдельный раздел?
